# Obsidian-plugin-template
script for create dev environment for develop obsidian plugin

use this command

```bash
curl -fsSL https://raw.githubusercontent.com/knakto/Obsidian-plugin-template/main/init.sh | sh
```

or

```bash
wget -qO- https://raw.githubusercontent.com/knakto/Obsidian-plugin-template/main/init.sh | sh

```
